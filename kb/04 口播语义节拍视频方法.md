# 口播语义节拍视频方法

![[Assets/skill-showcase-v3-effects.jpg|820]]

## 核心方法

```text
口播 -> 句级时间戳 -> 章节 Scene -> 语义 Beat -> 视觉证明 -> 帧动画
```

旧方法通常是“数据进入模板，然后播放一次入场动画”。它适合数字、对比和架构图，但无法稳定承载十几秒的连续口播。

语义节拍方法把每个 Scene 继续拆成多个 Beat。每个 Beat 明确：

- 什么时候出现
- 当前最重要的关键词
- 使用哪个语义图标
- 触发什么强调动作
- 观众应该看哪里

## 三层画面

1. 顶部：章节编号、主图标、标题和进度色条。
2. 中部：代码、编辑器、流程或对比等视觉证明。
3. 底部：当前完整口播字幕。

关键词 Beat 放在主体与字幕之间，不重复整句字幕。

## 四层文字

| 层级 | 职责 |
|---|---|
| 章节标题 | 现在讲哪个能力 |
| 关键词 | 这一秒最重要的判断 |
| 解释标签 | 视觉证明中应该看哪里 |
| 字幕 | 完整承接口播 |

## 三层特效

- 持续层：扫描线、五组细线位移、确定性颗粒、景深框推进、色差边缘、焦点扫光和彩色图标慢漂。所有变化由当前帧计算，长镜头持续有呼吸。
- 节拍层：八种构图动作、前后图标接力、局部框选、证据堆叠、数值计数和结论爆发。每 2-4 秒发生一次语义变化。
- 转场层：章节色条横扫、图标接棒和 12 帧短闪切，与 Scene 转场同时工作。

特效必须能对应明确口播，不能只为了让画面更热闹。

固定映射真源是 `iconRegistry.ts`。当前静态资产 76 个，样片 57 个 Beat 实际使用 39 个图标。

## 八种 Beat 动作

| Action | 适用重音 |
|---|---|
| `stamp` | 章节名和强判断 |
| `spotlight` | 单一正向结论 |
| `trace` | 路径、输入输出和过程 |
| `compare` | 前后、正反和断点 |
| `counter` | 数量、通过率和可验证结果 |
| `stack` | 多项证据、步骤和组成 |
| `focus` | 需要局部框选的核心对象 |
| `burst` | 章节结论和能力释放 |

## 重音帧换算

Beat 不再凭感觉写秒数。先累计前置 Scene 得到 `sceneStartFrame`，再从字幕时间戳换算局部帧：

```text
globalFrame = round(timestampMs / 1000 * fps)
localFrame  = globalFrame - sceneStartFrame
```

当前样片的 57 个 Beat 都按这个规则重排到句级边界和章节边界。句内快速列举只在主画面内部继续分相，例如“排版、留白、配色”共享一个 72 帧 Beat，三个 UI Token 在该 Beat 内依次接力。

项目级硬规则：

- 每个 `skill-showcase` Scene 都必须有 Beat，开场、总览和结尾不能空。
- 全片第一个 Beat 必须从第 0 帧开始。
- 每个 Scene 的第一个 Beat 必须在局部 1 秒内出现。
- 每个 Scene 的最后一个 Beat 必须贴到 scene 结尾。
- 相邻 Beat 之间不能出现肉眼可见的长空窗。

## 制作顺序

1. 锁定最终口播和音频。
2. 获取句级时间戳。
3. 根据内容转折切 Scene。
4. 将 Scene 时间换算为整数帧。
5. 写入每章 Beat。
6. 为 Beat 选择关键词、图标和 action。
7. 先检查关键帧。
8. 关键帧通过后才渲染完整 MP4。
9. 最终 MP4 必须通过成品守门脚本。

## 成品守门线

当前样片已经从关键帧验证升级为完整成品基线：

- 成品视频：`remotion-video/out/workbuddy-six-skills-showcase-v3.mp4`
- 预览帧：`remotion-video/out/workbuddy-six-skills-showcase-v3-preview.jpg`
- 关键帧联系表：`remotion-video/out/skill-showcase-v3-qa/contact-sheet.jpg`

固定命令：

```bash
cd remotion-video
npm run skill:gate
npm run skill:render
npm run skill:verify
```

`skill:gate` 检查 Project 合同、9 个章节、3649 帧、57 条句级字幕、必需语音、57 个 Beat、8 种 action、12 类图标包和 76 个本地 SVG。`skill:verify` 会进一步检查最终 MP4 的 H.264 视频、AAC 音频、1080x1920、30fps、121.63 秒视频流和完整解码。
