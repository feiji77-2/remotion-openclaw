# 当前代码地图

## 生产渲染

| 路径 | 所有权 |
|---|---|
| `remotion-video/src/Root.tsx` | 两个 Composition 的唯一注册点 |
| `remotion-video/src/compositions/v2/UltimateVideoV2.tsx` | 成片 Composition |
| `remotion-video/src/project/projectSchema.ts` | Project JSON 基础 Schema |
| `remotion-video/src/project/compileProject.ts` | 时间、字幕、资产和 scene 编译 |
| `remotion-video/src/project/sceneRegistry.tsx` | 唯一 family 和 payload Schema |
| `remotion-video/src/timeline/` | scene、字幕、音频和全局层编排 |

## 20 主视觉

| 路径 | 所有权 |
|---|---|
| `.../skill-showcase/SkillShowcase.tsx` | scene 入口 |
| `.../skill-showcase/skillShowcaseRouting.ts` | Cinematic / Hero Track 唯一路由 |
| `.../skill-showcase/PortraitCinematicSkillShowcase.tsx` | 11 Cinematic preset |

上表 `.../skill-showcase/` 的完整前缀是 `remotion-video/src/components/ultimate-kit/families/skill-showcase/`。

## 输入、产物与证据

- `remotion-video/examples/skill-showcase.json`：黄金 Project JSON。
- `remotion-video/projects/**`：真实本地项目输入，任何清理任务都不得默认删除。
- `remotion-video/public/**`：Remotion 静态资产根目录。
- `remotion-video/out/**`：渲染产物；当前黄金 MP4 和两类接触表是验收证据。
- `.agentdesk/**`：任务卡、决策、合同、报告和测试记录。
