# 当前唯一生成链路

## 端到端数据流

```text
口播稿 / 时间字幕 / 控制台生产包
  -> scripts/lib/script-project-generator.mjs
  -> examples/skill-showcase.json 或 projects/<id>/project.json
  -> src/project/projectSchema.ts
  -> src/project/compileProject.ts
  -> src/compositions/v2/UltimateVideoV2.tsx
  -> src/timeline/SceneTimeline.tsx
  -> src/project/sceneRegistry.tsx
  -> SkillShowcase.tsx
  -> resolveSkillShowcaseRenderPlan()
       -> cinematic      -> PortraitCinematicSkillShowcase.tsx
       -> hero-track-v2  -> HeroTrackV2.tsx
  -> Still / MP4 / QA / Verify
```

控制台不是第二条链路。`scripts/tools-studio-server.mjs` 创建四文件生产包，`starter-project.mjs` 与 `build-project-from-production.mjs` 最终都复用 `buildSkillShowcaseProjectFromScript()`。

## 两种渲染模式

- `payload.heroStyle = "cinematic"`：Beat 使用 11 个 `shotPreset`，由 Cinematic 实现渲染。
- `payload.heroStyle = "hero-track-v2"` 或存在 `payload.heroTrack`：使用 9 个 Hero Track kind。
- 未显式指定时，`resolveSkillShowcaseRenderPlan()` 合成 Hero Track；不会进入第三个 renderer。

## 两个 Composition

- `UltimateVideoV2`：真实 Project JSON 的成片渲染入口。
- `RemotionStoryboardLibrary`：20 个主视觉组件的固定画面验收入口，不是第二套成片系统。

## 三个容易误认的“9”

- 黄金样片有 9 个 scene，它们是具体成片段落。
- `out/skill-showcase-v3-current-midpoints/contact-sheet.png` 有 9 个场景中点，用于检查该样片。
- Hero Track 有 9 个 kind，它们是可复用的主视觉实现。

`payload.variant` 只是内容语义和默认映射提示，不是第三套渲染器。当前组件目录的唯一事实源是 `storyboardContract.json` 中的 11 + 9。
