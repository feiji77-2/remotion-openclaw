# 控制台与生成命令

## 启动控制台

```bash
cd remotion-video
npm run tools:studio
```

默认地址为 `http://127.0.0.1:8787/`。端口冲突时使用 `VIDEO_FACTORY_PORT=8788 npm run tools:studio`。

控制台项目包含：

```text
projects/<id>/
  brief.json
  script-pack.json
  asset-pack.json
  project.json
```

前 3 个文件是生产输入，`project.json` 是唯一 Remotion 渲染输入。控制台只接受竖屏；样式卡只改变同一 20 组件体系的色彩与字幕表现。

## API

| 方法 | 路径 | 作用 |
|---|---|---|
| `GET` | `/api/health` | 健康状态 |
| `GET` | `/api/projects` | 列出样例和本地项目 |
| `POST` | `/api/projects` | 创建四文件生产包 |
| `GET/POST` | `/api/files` | 读写四类 JSON 文件 |
| `POST` | `/api/jobs` | 启动 build/check/still/render/verify |
| `GET` | `/api/jobs/:id` | 查询任务状态与日志 |
| `GET` | `/api/artifact` | 读取 PNG、MP4 或 JSON 产物 |

## CLI

```bash
# 从口播生成
npm run project:from-script -- --id demo --title "演示" --script-file ./script.txt --out projects/demo/project.json

# 从生产包重建
npm --prefix remotion-video run project:from-pack -- projects/demo

# 校验、Still、QA、MP4、媒体核验
npm run project:check -- projects/demo/project.json
npm run project:still -- projects/demo/project.json --frame 60 --out out/demo-f60.png
npm --prefix remotion-video run project:qa-sheet -- projects/demo/project.json --render
npm run project:render -- projects/demo/project.json --out out/demo.mp4
npm --prefix remotion-video run project:verify -- --props projects/demo/project.json --video out/demo.mp4
```

从仓库根目录执行 `npm run project:*` 时，输入和输出路径均相对于 `remotion-video/`。
