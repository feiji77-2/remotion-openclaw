## QA 层分三类

### 1. 工程 QA

- `npm run typecheck`
- `node --test server/tests/*.test.js`

### 2. Storyboard QA

- 通过 `--with-storyboard-qa`
- 生成静态分镜图
- 不阻塞主链路

### 3. Render / Visual QA

- `preview-quick.mjs`
- `snapshots.mts`
- `verify-render-output.mjs`

`snapshots.mts` 当前已经支持两种用法：

- 全量回归：`npx tsx scripts/snapshots.mts render`
- 定向抽帧：`npx tsx scripts/snapshots.mts render hero terminal code`

当前快照链路已经是带导演夹具的回归图，不再是早期组件快照，实际覆盖：

- `cameraMotion`
- `revealDirection`
- `archetype`
- `dataEvent`
- `memoryObject`

截至 2026-05-01，导演夹具回归已覆盖全部 `20` 个 family。

## 验收顺序建议

1. `npm run typecheck`
2. `node --test server/tests/*.test.js`
3. `preview-quick.mjs`
4. `snapshots.mts diff`
5. `verify-render-output.mjs`
6. 最后人工看成片

## Storyboard QA 输出路径

```text
projects/<projectId>/qa/storyboard/
├── storyboard-manifest.json
└── images/
```

## 最终产物验收关注点

- 场景切换是否连贯
- 字幕与语音是否同步
- 图表、对比、数据是否和 payload 一致
- 9:16/16:9 是否符合当前模板目标
- 音量淡入淡出是否自然

## 导演层提醒

现在项目除了传统 QA，还有“导演层 QA”的强校验。

当前已经实际接入的地方：

- `storyboardLoader.ts` 会在场景归一化阶段执行 `directorQA`
- `snapshots.mts` 已切到导演夹具快照，不再只是早期组件图
- 多核 family 如果导演原型不合法，会直接阻塞渲染而不是静默通过
