# 换稿视觉合同防污染

## 问题根源

这次暴露的问题不是 TTS，也不是 Remotion 没接收到 props，而是换口播时只更新了 `captions` 和音频，`scene.payload` 仍然保留旧复刻样片的视觉身份。

表现：

- 配音和字幕是新稿。
- 开场、总览、结尾仍出现旧项目品牌、旧技能名、旧图标。
- 章节数量、产品图标和进度条仍像上一条样片。
- 旧 `projectId` 仍然叫黄金样片，但 captions 已经不是黄金样片口播。

## 新红线

- 禁止只换 `captions` / `voice.m4a` 就渲染成品。
- 新口播必须同步生成或手动更新 `scenes[].payload`。
- `intro`、`overview`、`outro` 不能依赖组件内部旧默认文案。
- 新项目必须声明 `brandName`、`headline` 或 `body`、`labelIcons`、`productIcons`。
- 主体章节必须声明 `productIcon` 和 `progressIndex/progressTotal`。
- 新项目每个 `skill-showcase` Scene 必须声明 `sourceText`，且 `sourceText` 必须来自当前 captions。
- 新项目每个 `skill-showcase` Scene 必须声明连续 `captionRange`，Scene 时长只能由该区间字幕换算，误差不得超过 1 帧。
- 新项目每个 Beat 必须声明 `captionStartIndex/captionEndIndex`、`visualState`、`motionPreset` 和 `placement`。
- Beat 的本地 `startFrame/endFrame` 必须由绑定字幕毫秒换算，不能按 Scene 长度平均铺开。
- 禁止用 WorkBuddy 黄金样片 `projectId` 承载新口播。

## 新增守门

```bash
cd /Users/macos/OpenClaw/remotion-generated-video-project/remotion-video
npm run project:visual-check -- examples/design-skills-showcase.json
npm run project:check -- examples/design-skills-showcase.json
```

`project:check` 已接入视觉合同检查，会先拦截：

- `skill-showcase` Scene 没有 Beat。
- 新口播项目 Scene 没有 `captionRange`。
- Scene 时长与 `captionRange` 换算结果超过 1 帧。
- Beat 没有绑定字幕索引，或绑定字幕越出当前 Scene。
- Beat 关键词不来自绑定字幕或明确 Beat 摘要。
- 第一个 Beat 太晚。
- 最后一个 Beat 没覆盖到 Scene 结尾。
- 新项目 intro/overview/outro 没有声明品牌、图标和新片文案。
- 非黄金样片的视觉 payload 混入 WorkBuddy、PPT Master、HyperFrames 等旧样片词。
- 产品图标声明了但本地 SVG 不存在。
- 新项目 Scene 没有 `sourceText`。
- `sourceText` 在当前 captions 中找不到。
- `project:still` 和 `project:render` 已经接入同一视觉合同，污染项目会在出图前失败。

## 正确换稿流程

```text
新口播
  -> project:from-script
  -> captions
  -> scene 切分
  -> scene.captionRange
  -> 每个 scene.payload 写标题、主体文案、图标、sourceText、Beat
  -> 每个 Beat 绑定 captionStartIndex/captionEndIndex
  -> project:visual-check
  -> project:check
  -> project:qa-sheet
  -> 关键帧 still
  -> 完整渲染
```

换稿的最低标准：视觉合同必须能解释当前口播，而不是继承上一条视频的解释。

命令：

```bash
cd /Users/macos/OpenClaw/remotion-generated-video-project/remotion-video
npm run project:from-script -- --id new-topic --title "新标题" --script-file /absolute/path/script.txt --out examples/new-topic.json
npm run project:visual-check -- examples/new-topic.json
npm run project:qa-sheet -- examples/new-topic.json --out-dir out/new-topic-qa
npm run project:still -- examples/new-topic.json --frame 60 --out out/new-topic-f60.png --scale=0.5
```
