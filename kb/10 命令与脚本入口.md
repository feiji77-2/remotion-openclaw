# 命令与脚本入口

## 工作目录

所有视频工程命令默认在这里执行：

```bash
cd /Users/macos/OpenClaw/remotion-generated-video-project/remotion-video
```

## 日常开发检查

```bash
npm run skill:gate
npm run project:check -- examples/skill-showcase.json
npm run typecheck
npm test
```

用途：

- `skill:gate`：检查当前样片方法、资产、图标、Beat 和成品合同。
- `project:check`：检查 Project schema、family、payload、资产和总时长。
- `typecheck`：检查 TypeScript。
- `npm test`：跑单元测试。


```text
out/workbuddy-six-skills-showcase-v3.mp4
```

## 成品验证

```bash
npm run skill:verify
```

验证内容：

- Project 仍为 `examples/skill-showcase.json`
- 9 个 Scene、3649 帧、57 条字幕、57 个 Beat
- 全片首个 Beat 从第 0 帧开始
- intro、overview、outro 也有 Beat
- 8 种 Beat action 覆盖
- 12 类图标包存在
- 76 个本地 SVG 存在
- 7 个商品/Skill 彩色 SVG 存在
- Lucide 许可证存在
- MP4 视频流为 H.264
- 音频流为 AAC
- 画幅为 `1080x1920`
- 帧率为 `30fps`
- 时长约 `121.63s`
- FFmpeg 可完整解码

## 脚本文件

| 命令 | 脚本 |
|---|---|
| `npm run project:check` | `scripts/check-project.mjs` |
| `npm run project:still` | `scripts/render-project-still.mjs` |
| `npm run project:render` | `scripts/project-render.mjs` |
| `npm run skill:gate` | `scripts/check-skill-showcase-production.mjs --no-video` |
| `npm run skill:render` | `scripts/project-render.mjs examples/skill-showcase.json --out out/workbuddy-six-skills-showcase-v3.mp4` |
| `npm run skill:verify` | `scripts/check-skill-showcase-production.mjs --video out/workbuddy-six-skills-showcase-v3.mp4` 和 `scripts/verify-project-render.mjs` |

## 注意

不要用旧的 `build:verify` 默认参数验证当前样片。当前样片的成品验收入口就是 `skill:verify`。
