# 失败案例对照

## 这页的定位

这页不是为了挑刺，是为了帮你少走弯路。

核心原则只有一句：

`能结构化的数据，不要只写成 narration。`

## 共性失败模式

### 1. 只写标题和旁白，不写结构字段

结果：

- family 名字对了
- 但组件吃不到真正的数据
- 最后出来的是空壳

### 2. family 选对了，但喂错字段

比如：

- `feature-rail` 用 `items[]` 代替 `features[]`
- `tag-matrix` 没给 `tabs`
- `terminal` 没给 `outputs`

### 3. 想要对比，却不给两边值

这是 `compare-board` 和 `benchmark-chart` 最常见问题。

### 4. 想要工程感，却只写大而空的概念词

比如写：

- “系统更强”
- “架构升级”
- “工作流更完整”

但没有节点、阶段、命令、参数、来源。

### 5. 结尾还在解释，不在收束

这是 `cta`、`quote-highlight` 最常见失手点。

## 最常见的 10 组错误

| 目标 | 错误写法 | 正确方向 |
|---|---|---|
| `feature-rail` | 只写 `items[]` | 写 `features[]`，每张卡有 `title + desc` |
| `timeline` | 只写一条 narration | 写至少 3 个 `items[]` 节点 |
| `compare-board` | 只有 `comparisons[]` 没左右值 | 同时给 `dataPoints[]` |
| `terminal` | 只有 `command` 没 `outputs` | 至少给 2-3 行输出 |
| `metrics` | dataPoints 没 ratio | 用 `标签:值:ratio` |
| `benchmark-chart` | dataPoints 只有单值 | 用 `标签:主值:副值:ratio` |
| `tag-matrix` | 没 tabs 只有 items | 至少给 `tabs` + `activeTab` |
| `architecture-map` | 没 centerTitle | 明确中心节点 |
| `quote-highlight` | narration 太长像段落 | 写成能一屏打住的短句 |
| `cta` | 继续讲知识点 | 标题变动作句，副标题做收口 |

## 最稳的修法

1. 先确认 family 对不对
2. 再看 `storyboardLoader.ts` 这一 family 真正吃什么
3. 把 Step-04 改成结构化字段
4. 先跑 still，再跑 540p
