# 项目总览

## 项目目标

这个项目的目标不是单纯“把字幕和配音拼成视频”，而是做一个：

- 可检索事实
- 可生成口播
- 可拆分镜
- 可生成视觉提示词
- 可合成配音
- 可直接渲染成片
- 可做 Storyboard QA 和 Render QA

的 Remotion 生产系统。

## 当前核心规格

- 默认模板：`ultimate`
- 默认视觉系统：`ultimate-1080p`
- 默认分辨率：`1920x1080`
- 默认帧率：`30fps`
- 语音链路：`qwen-tts`
- 内部步骤：`step 1` 到 `step 8`
- 外显阶段：`phase 1` 到 `phase 6`

## 当前知识面

这个项目现在已经不只是一个 Remotion 前端仓库，而是五层结构：

1. Workflow 层：研究、标题、文案、分镜、视觉提示词、配音、出片
2. Project 层：把 workflow 产物落到 `projects/<projectId>/`
3. Render 层：把 Step-04 / project 数据变成 `UltimateSceneTemplate`
4. QA 层：Storyboard QA、snapshots、typecheck、server tests
5. Director 层：shot grammar、camera intent、data event、memory object

## 重点认知

这个项目最容易混淆的点是：

- “项目结构” 和 “渲染结构” 不是一回事
- “family 模板” 和 “导演层 shot grammar” 不是一回事
- “step 1-8” 和 “phase 1-6” 不是一回事
- “Storyboard QA” 和 “最终渲染 QA” 不是一回事
