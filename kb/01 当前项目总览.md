# 当前项目总览

## 项目目标

当前工程负责把一段完整中文口播，稳定生产成一条可验证、可复刻、可继续打磨的竖屏动效视频。它不是屏幕录制教程，也不是随机模板套壳，而是一条帧确定的编辑型视频管线。

工程必须保证：

- 输入可校验
- 场景时长可计算
- 字幕和音频与帧时间轴一致
- Family payload 在渲染前失败，而不是渲染中黑屏
- 关键帧与最终 MP4 使用同一套代码
- 成品 MP4 有明确规格并能完整解码

## 边界

准备阶段可以生成文案、配音、截图和素材，但这些任务必须在 Project JSON 之前完成。Remotion 渲染过程中不访问 LLM、TTS 或不稳定的远程服务。

这个项目当前最应该继续投入的是：

- 增加更多可复用 Scene 视觉变体。
- 扩展 Beat action 的视觉语言，但保持 schema 和 gate 同步。
- 增强语音重音绑定，让关键词和图标更贴近句内重拍。
- 扩展图标映射和本地资产库。
- 把关键帧 QA 继续自动化。

不应该回到的方向：

- 纯 MockTerminal 操作教程。
- 真实软件录屏模拟。
- 依赖运行时截图、搜索、LLM 或 TTS。
- 没有 Beat 的长镜头模板动画。

## 当前成品流程

```bash
cd remotion-video
npm run skill:gate
npm run project:check -- examples/skill-showcase.json
npm run typecheck
npm test
npm run skill:render
npm run skill:verify
```

`skill:gate` 是方法级约束，确认样片仍然是口播语义节拍视频；`skill:verify` 是成品级约束，确认最终 MP4 可播放、可解码且音视频规格正确。
