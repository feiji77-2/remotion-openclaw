# QA 与视觉验收

## 自动化门槛

```bash
npm run typecheck
npm test
npm run project:check -- examples/skill-showcase.json
npm --prefix remotion-video run skill:gate
npm --prefix remotion-video run storyboard:check
npm --prefix remotion-video run tools:build
```

涉及控制台或真实输出时继续运行：

```bash
npm --prefix remotion-video run test:e2e
npm --prefix remotion-video run test:visual-e2e
npm --prefix remotion-video run test:ui
npm --prefix remotion-video run skill:verify
npm --prefix remotion-video run storyboard:render
```

## 三类视觉证据

| 证据 | 回答的问题 |
|---|---|
| `out/skill-showcase-still.png` | 单帧是否真实、非空、尺寸正确 |
| `out/skill-showcase-v3-current-midpoints/contact-sheet.png` | 黄金样片 9 个 scene 的节奏和版式是否正常 |
| `out/remotion-storyboard-library/contact-all-20.png` | 11 Cinematic + 9 Hero Track 是否全部可见且互不重复 |

## 判定规则

自动化退出码只能证明脚本执行和机器可检查合同，不等于画面审核通过。最终验收必须直接打开真实 PNG 或 MP4，检查：

- 没有黑帧、透明空白或资源加载失败。
- 标题、主视觉、语义层和字幕没有不合理重叠。
- 主要文字没有裁切或越界。
- 20 个目录画面不是重复占位图。
- 字幕、Beat、Hero state 与口播时间连续。
- MP4 为 H.264/AAC、`1080x1920`、`30fps`，帧数和 Project JSON 一致。

任何未直接查看的视觉证据只能标为“待人工检查”或“inconclusive”，不能写成通过。
