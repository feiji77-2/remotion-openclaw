
## 当前音频

```text
public/projects/skill-showcase/audio/voice.m4a
```

音频是当前样片时间轴真源之一。字幕、Scene duration 和 Beat start/end 都必须跟它对齐。

当前生产音频规格：

| 项目 | 当前值 |
|---|---|
| 编码 | AAC |
| 采样率 | 44100 Hz |
| 声道 | 2 |
| 时长 | 约 `121.626s` |
| Project 时长 | 约 `121.633s` |

配音生成入口：

```bash
cd /Users/macos/OpenClaw/remotion-generated-video-project/remotion-video
npm run tts:project -- examples/skill-showcase.json --out tmp/tts-chain-smoke.m4a
```

注意：

- `--out` 指到 `tmp/` 只能做 smoke，不会被 Remotion `staticFile()` 直接引用。
- 正式替换配音时，输出必须在 `public/` 下，Project JSON 里的 `assets.voiceover.src` 必须是相对 `public/` 的路径。
- 当前实测从 captions 重新生成的 Qwen 配音约 `149.920s`，长于当前项目时间线约 `28.287s`，不能直接覆盖 `voice.m4a`。
- 重新配音必须同时重算 captions、Scene duration 和 Beat start/end。

彩色图标出场后必须有低频漂浮：

- 固定尺寸盒子不改宽高，避免卡片和文字抖动。
- 图标本体只做 2-4px 慢漂、1-2 度微旋转和轻微光晕呼吸。
- 动效必须由 `useCurrentFrame()` 驱动，禁止 CSS animation。
- 漂浮是持续层，不替代 Beat 关键词、图标接力和局部高亮。

## 新增图标流程

1. 把 SVG 放入 `public/projects/skill-showcase/icons/`。
2. 在 `iconRegistry.ts` 注册 id、文件名、语义包、标签。
3. 如新增语义包，同步 `types.ts`、schema、gate 和知识库。
4. 在 `examples/skill-showcase.json` 的 Beat 中引用图标 id。
5. 跑 `npm run skill:gate`。
6. 跑关键帧检查，确认图标不是空白、不是错义、没有遮挡字幕。

## 新增商品彩色图标流程

1. 把 SVG 放入 `public/projects/skill-showcase/product-icons/`。
2. 在 `productIcons.ts` 注册文件名。
3. 在 `SkillShowcase.tsx` 的 `VARIANT_PRODUCT_ICON` 或 `SUMMARY_PRODUCT_ICONS` 中绑定使用位置。
4. 黄金样片必需图标才加入 `check-skill-showcase-production.mjs`；通用换稿图标由 `project:visual-check` 检查存在性。
5. 跑 `npm run skill:gate` 和关键帧 still。

## 图标使用原则

- 图标不是装饰，是口播关键词的语义锚点。
- 同一 Beat 的 icon、keyword、action 必须表达同一个判断。
- 图标在相邻 Beat 中可以接棒，但不能随机乱跳。
- 长章节中每 2-4 秒至少出现一次关键词、图标、局部高亮或证据变化。
- 图标和文字不能突破固定尺寸，避免布局抖动。
