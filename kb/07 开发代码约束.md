# 开发代码约束

## 定位

这份约束用于保护当前已经跑通的 `skill-showcase` 成品流程。它不是通用代码风格，而是后续继续打磨特效、文字展示、图标映射、字幕和成片验收时必须遵守的工程边界。

完整主文档：

`remotion-video/docs/development-code-constraints.zh-CN.md`

## 当前成品路径

```text
新口播/字幕 -> project:from-script -> Project JSON -> visual contract -> compileProject -> UltimateVideoV2 -> SceneTimeline -> skill-showcase -> Caption/Audio -> MP4 -> Verify
```

当前基线：

- Project：`remotion-video/examples/skill-showcase.json`
- MP4：`remotion-video/out/workbuddy-six-skills-showcase-v3.mp4`
- Gate：`remotion-video/scripts/check-skill-showcase-production.mjs`

## 核心红线

- 禁止绕过 `VideoProjectSchema`。
- 禁止 render 期间访问 LLM、TTS、搜索、截图或不稳定远程服务。
- 禁止 CSS animation、timer、真实时间和运行时随机数驱动画面。
- 禁止把绝对路径写进 Project asset。
- 禁止长章节只做一次入场动画。
- 禁止开场、总览或结尾没有语义 Beat。
- 禁止只更新 captions/audio 而不更新 scene payload。
- 禁止新项目 intro、overview、outro 继续吃旧样片默认品牌、图标或收束文案。
- 禁止新项目缺少 `scene.payload.sourceText`。
- 禁止用 WorkBuddy 黄金样片 `projectId` 承载新口播。
- 禁止新稿连续三个 `skill-showcase` Scene 复用同一 `layoutSignature`。
- 禁止忽略口播里的结构信号：第一/第二/第三、但是/然而、此外/另外、因为/所以、数字范围词都必须影响 Scene 和 Beat。
- 禁止字幕、标题、关键词重复同一整句。
- 禁止把图标当随机装饰。
- 禁止顺手删除或重构无关文件。

| `examples/skill-showcase.json` | 成品样片真源，改后必须跑 `skill:gate` |

| `src/timeline/` | Scene、Caption、Audio 时间线，必须保持帧确定性 |
| `src/components/ultimate-kit/families/skill-showcase/` | 当前成品 family，视觉打磨优先在这里完成 |
| `public/projects/skill-showcase/` | 本地语音、图标和资产，路径必须相对 `public/` |
| `scripts/check-skill-showcase-production.mjs` | 成品守门，失败必须 exit 非 0 |
| `scripts/lib/visual-contract.mjs` | 换稿防污染守门，失败必须 exit 非 0 |
| `scripts/build-skill-showcase-from-script.mjs` | 新口播生成新 Project，不从旧样片替换 |
| `docs/` 和 `kb/` | 合同、方法和验收同步 |

## 变更 Playbook 摘要

| 任务 | 第一改动点 | 必跑 |
|---|---|---|
| 调整关键词时间 | `examples/skill-showcase.json` | `npm run skill:gate` |
| 新增 Beat action | `types.ts`、`sceneRegistry.tsx`、`SemanticLayers.tsx` | `npm test`、`npm run skill:gate` |

## 叙事信号合同

`scripts/lib/script-project-generator.mjs` 是叙事结构识别入口。新增或调整信号时，必须同步：

- `narrativeSignal.key/family`
- Scene `visualMode`
- Scene `layoutSignature`
- Beat `action`
- Beat `motionPreset`
- Beat `placement`
- `src/project/__tests__/project.test.ts` 回归用例

默认映射：

| 文案信号 | Scene 目标 |
|---|---|
| 第一/第二/第三 | 编号递进和步骤流 |
| 左右/大约/接近/数字 | 数字条或范围结论 |
| 等等/此外/另外 | 标签矩阵和列表展开 |
| 但是/然而/不过 | 对比分屏 |
| 因为/所以/因此 | 因果流程和聚焦图 |

## Beat 覆盖硬规则

- 每个 `skill-showcase` Scene 都必须有 Beat。
- 全片首个 Beat 必须从第 0 帧开始。
- 每个 Scene 的第一个 Beat 必须在局部 1 秒内出现。
- 每个 Scene 的最后一个 Beat 必须到达 `durationInFrames`。
- 相邻 Beat 之间不能出现肉眼可见长空窗。
- 新稿每个 Scene 必须有 `sourceText`，并且来自当前 captions。
