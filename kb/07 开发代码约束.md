# 开发代码约束

> 本页是 kb 速查入口，不再维护第二份完整约束。
> 完整红线只看：`remotion-video/docs/development-code-constraints.zh-CN.md`

## 一句话

任何开发都必须保护这条链路：

```text
Project JSON -> VideoProjectSchema -> compileProject() -> UltimateVideoV2 -> Still / MP4 -> QA
```

## 最高红线

- 禁止绕过 `VideoProjectSchema`。
- 禁止 render 期间访问 LLM、TTS、搜索、截图、数据库或队列。
- 禁止 CSS animation、timer、真实时间和运行时随机数驱动画面。
- 禁止把绝对路径、`public/` 前缀或 `..` 写进 asset。
- 禁止 schema 失败后静默 fallback。
- 禁止新增 family 只改 registry、不接组件、不补示例。
- 禁止把 P2 的 API、DB、Queue、Worker 写成当前已存在能力。
- 禁止维护第二份全量 family/schema/架构事实表。
- 禁止一次性计划稿或旧规格继续挂在主文档入口。
- 禁止顺手删除、重构或格式化无关文件。
- 禁止把“Remotion 生图 / 分镜图”默认理解为 AI 生图；除非用户明确要求生成式图片。
- 禁止 Hero Visual 重复完整口播或覆盖核心技术实体；完整口播只进 Caption。
- 禁止批量静帧复用一次 `selectComposition` 的 props；每个 index 必须重新选择并检查内容唯一性。

## 固定验收

```bash
cd remotion-video
npm run typecheck
npm test
npm run project:check -- examples/project.json
npm run project:still -- examples/project.json --frame 30 --out out/project-f30.png --scale 0.25
npm run storyboard:check
```

成品级再跑：

```bash
npm run project:render -- examples/project.json --out out/project-smoke.mp4 --frames 0-119
npm run project:verify
```

`project:still` 必须带 Project JSON 参数；只打印 usage 不算通过。
