# Remotion 视频工厂知识库

> 当前版本：2026-07-21。这里只记录仓库现行事实，不保存退役架构、旧 family 或历史渲染器的开发记忆。

## 唯一生产链路

```text
控制台 / project:from-script
  -> skill-showcase Project JSON
  -> VideoProjectSchema / compileProject
  -> UltimateVideoV2
  -> 11 Cinematic + 9 Hero Track
  -> Still / MP4 / QA / Verify
```

固定合同：`1080x1920`、`30fps`、竖屏、一个 `skill-showcase` scene family、两个 renderer mode，以及两个注册的 Remotion Composition。

## 事实源优先级

发生冲突时按以下顺序判断：

1. 运行中的源码、Schema 和 `package.json` 脚本。
2. `.agentdesk/CONTRACTS.md`、`.agentdesk/DECISIONS.md` 和 `.agentdesk/PM_STATE.md`。
3. `docs/`、`remotion-video/docs/` 和本知识库。
4. 对话记录、旧视频名称或未接入主链路的文件不能覆盖上述事实源。
