# 字段命中示例库

## 这页是干什么的

这页不是讲“审美建议”，而是讲：

- 每个 family 在 `storyboardLoader.ts` 里真正吃什么字段
- 你在 Step-04 里应该优先写哪些字段
- 最小可用示例长什么样

## 使用原则

- `family` 决定大方向
- `title` 和 `narration` 永远别偷懒
- 能结构化就结构化，不要什么都塞进 narration
- 以 `payload.shots[]` 的写法理解最直接

## 最小字段速查

| Family | 最该喂的字段 | 少了会怎样 | 详情 |
|---|---|---|---|
| `hero` | `visual.props.lines` / `heroEmoji` / `brandIcon` | 退回普通标题屏 | [[Families/hero]] |
| `feature-rail` | `features[]` | 容易变空卡组 | [[Families/feature-rail]] |
| `focus` | `visual.props.keyword` / `description` | 变成普通标题聚焦 | [[Families/focus]] |
| `number-strip` | `visual.props.count` + `items[]` | 数字冲击感弱 | [[Families/number-strip]] |
| `step-flow` | `items[]` | 没有步骤感 | [[Families/step-flow]] |
| `timeline` | `items[]` | 没有节点推进 | [[Families/timeline]] |
| `compare-board` | `comparisons[]` + `dataPoints[]` | 只剩左右空板 | [[Families/compare-board]] |
| `terminal` | `visual.props.command` + `outputs[]` | 终端证据感缺失 | [[Families/terminal]] |
| `evidence-wall` | `comparisons[]` | 没有卡片证据墙 | [[Families/evidence-wall]] |
| `architecture-map` | `items[]` + `visual.props.centerTitle` | 中心节点不成立 | [[Families/architecture-map]] |
| `tag-matrix` | `visual.props.tabs` + `items[]` | 矩阵分组弱 | [[Families/tag-matrix]] |
| `code` | `visual.props.lines[]` | 退成普通代码壳 | [[Families/code]] |
| `metrics` | `dataPoints[]` 形如 `标签:值:ratio` | 比例条失真 | [[Families/metrics]] |
| `data-stream` | `dataPoints[]` 形如 `标签:值` | 流信号不成立 | [[Families/data-stream]] |
| `memory-graph` | `items[]` + `centerTitle` | 图谱关系弱 | [[Families/memory-graph]] |
| `pipeline-flow` | `items[]` | 阶段链路不成立 | [[Families/pipeline-flow]] |
| `benchmark-chart` | `dataPoints[]` 形如 `标签:主值:副值:ratio` | 跑分图不可信 | [[Families/benchmark-chart]] |
| `quote-highlight` | `narration` + `visual.props.attribution` | 金句没有来源 | [[Families/quote-highlight]] |
| `glossary-term` | `visual.props.term` + `narration` | 术语卡不聚焦 | [[Families/glossary-term]] |
| `cta` | `title` + `narration` | 结尾动作弱 | [[Families/cta]] |

## 你最该记的 6 条格式

### 1. `metrics`

```json
"dataPoints": ["渲染耗时:42秒:0.72", "人工修正:2轮:0.35"]
```

### 2. `benchmark-chart`

```json
"dataPoints": ["SWE-Bench:68.4:49.2:0.78", "Aider Polyglot:74.1:61.3:0.84"]
```

### 3. `data-stream`

```json
"dataPoints": ["tokens/s:182", "并发任务:12", "成功率:98.7%"]
```

### 4. `compare-board`

```json
"comparisons": [{"label":"链路","text":"8 步","secondary":"6 步"}],
"dataPoints": ["旧链路 / 新链路 / 0.75"]
```

### 5. `architecture-map` / `memory-graph` / `pipeline-flow`

```json
"items": [
  {"label":"调度层","detail":"workflowGenerator"},
  {"label":"转译层","detail":"storyboardLoader"},
  {"label":"渲染层","detail":"UltimateSceneTemplate"}
]
```

### 6. `hero`

```json
"visual": {
  "props": {
    "kicker": "GPT-5.5 发布",
    "heroEmoji": "🤖",
    "lines": ["编码代理更稳", "多代理并行更强", "桌面链路继续收口"]
  }
}
```
