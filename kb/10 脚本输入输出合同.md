# 脚本输入输出合同

## 一句话原则

所有脚本都不要当成“黑盒命令”来用。先看它读什么、写什么、成功时应该产出什么，再决定是跑它还是跳过它。

## 最重要的 11 个脚本

| 脚本                           | 作用                       | 主要输入                              | 主要输出                                                             | 什么时候用         |
| ---------------------------- | ------------------------ | --------------------------------- | ---------------------------------------------------------------- | ------------- |
| `run-search-to-ultimate.mjs` | 一站式主链路                   | topic / projectId / flags         | `projects/<id>/steps`、voice、images、render、phase report           | 真正跑项目         |
| `render-ultimate-scene.mjs`  | 用 Step-04 直接出片           | `step-04.json` 或 workflow payload | MP4                                                              | 验证 Step-04 渲染 |
| `preview-quick.mjs`          | still / sheet / 540p 快预览 | `step-04.json`                    | 预览图 / 预览视频                                                       | 调节奏与 family   |
| `verify-render-output.mjs`   | 校验最终视频合同                 | Step-04 / config / video          | 合同验证结果                                                           | 验收            |
| `generate-shot-images.mjs`   | 生成主链路图或 QA 图             | `projectId` + prompts json        | `public/assets/.../images` 或 `projects/.../qa/storyboard/images` | 图像资产          |
| `build-project-package.mjs`  | 把 project.json 编成可渲染包    | `project.json`                    | `image-prompts.json`、`render-props.json`、`ultimate-config.json`  | 包装与复用         |
| `render-project.mjs`         | 用 render props 出片        | `render-props.json`               | MP4 + staged render props                                        | 项目包渲染         |
| `doctor-render-env.mjs`      | 检查浏览器渲染环境                | 本机浏览器 / env                       | 健康检查结果                                                           | 渲染起不来时        |
| `snapshots.mts`              | still 回归快照               | 内置 20-family 导演夹具（支持定向 family） | `__snapshots__/families/*`、`manifest.json`                         | 视觉回归          |
| `clean-runtime.mjs`          | 清理 runtime               | 无或 flags                          | runtime 清理结果                                                     | 清缓存           |
| `voice/qwen-tts-voice.mjs`   | 千问 TTS 管理与试音             | command + voice/text/file         | JSON 结果或 wav                                                     | 配音调试          |

## 1. `run-search-to-ultimate.mjs`

真源位置：`remotion-video/scripts/run-search-to-ultimate.mjs`

输入：

- 主题：位置参数或 `--topic`
- 恢复项目：`--project-id <id> --resume`
- 可选开关：`--no-render`、`--no-images`、`--no-voice`、`--with-storyboard-qa`

读：

- `.env.local` / `.env`
- workflow generator
- qwen-tts
- 项目缓存与历史 step 产物

写：

- `remotion-video/projects/<projectId>/steps/*.json`
- `remotion-video/public/assets/<projectId>/images`
- `remotion-video/public/assets/voice/<projectId>`
- `remotion-video/public/assets/outputs/<projectId>`

成功信号：

- 控制台输出 phase / step 进度
- 最后打印 JSON report

最常见误用：

- 用 `--no-render` 后却以为它会自动出片
- 修改 Step-04 后没 `--resume`，导致数据被重新覆盖

## 2. `render-ultimate-scene.mjs`

真源位置：`remotion-video/scripts/render-ultimate-scene.mjs`

支持三种输入合同：

- `--config <step-04.json>`
- `--config <workflow_*.json>`
- `--outline <outline.json>` 这是兼容旧链路

主链路读：

- `storyboardLoader.node.ts`
- `shotsToScenes()`
- `calcTotalFrames()`

写：

- 默认输出 `out/ultimate-scene-template.mp4`
- 或 `--out <file>`

成功信号：

- dry-run 会列出 `Shots / Frames / Duration`
- 正式渲染会输出 `[render] Done: ...`

注意：

- Step-04 路径才是现在的真源
- `outline` 只是兼容路径，不应作为主开发链路

## 3. `preview-quick.mjs`

真源位置：`remotion-video/scripts/preview-quick.mjs`

输入：

- `--config <step-04.json>`
- `--mode still | sheet | 540p`

写：

- `previews/<config-name>-still-*`
- `previews/<config-name>-sheet.jpg`
- `previews/<config-name>-540p.mp4`

成功信号：

- 能读出 shots 数量
- 生成 still / sheet / 540p 成品

注意：

- `still` 和 `sheet` 偏诊断工具
- `540p` 更接近真实成片

## 4. `verify-render-output.mjs`

真源位置：`remotion-video/scripts/verify-render-output.mjs`

输入：

- `--step4 <step-04.json> --video <output.mp4>`
- 或 `--config <ultimate-config.json> --video <output.mp4>`

依赖：

- `ffprobe`
- 如果系统没有，会尝试 Remotion bundled ffprobe

校验项：

- 视频存在且非空
- 实际帧数接近期望帧数
- 实际时长接近期望时长

成功信号：

- 输出 `render contract verified`

## 5. `generate-shot-images.mjs`

真源位置：`remotion-video/scripts/generate-shot-images.mjs`

输入：

- `node scripts/generate-shot-images.mjs <projectId> [shotsJsonFile]`
- 或通过 stdin pipe 传入 JSON

支持的输入结构：

- `prompts.byShotId`
- `byShotId`
- 可附带 `shots[]`、`visualSystem`、`canvasWidth`、`canvasHeight`

写：

- 主链路模式：`public/assets/<projectId>/images`
- QA 模式：`projects/<projectId>/qa/storyboard/images`

stdout：

- 不是普通日志，而是进度事件 JSON

注意：

- `--qa-mode` 写的是 QA 目录，不会自动替代主链路图片

## 6. `build-project-package.mjs`

真源位置：`remotion-video/scripts/build-project-package.mjs`

输入：

- `node scripts/build-project-package.mjs <project-json-path>`

读：

- `project.json`
- 其中的 shots、render、template、visualSystem

写到 project 同目录：

- `image-prompts.json`
- `render-props.json`
- `ultimate-config.json` 仅 ultimate 模板时生成

成功信号：

- stdout 输出单行 JSON
- 里面包含 `imagePromptsPath`、`renderPropsPath`、`ultimateConfigPath`

## 7. `render-project.mjs`

真源位置：`remotion-video/scripts/render-project.mjs`

输入：

- `node scripts/render-project.mjs <render-props-json> [output-path] [...remotion-flags]`

读：

- `render-props.json`
- `render-defaults.js`

写：

- MP4 成片
- `public/runtime/render-props/<projectId>-*.json` staged render props

成功信号：

- 输出 composition / output / props-file / browser / port

注意：

- 如果是 Ultimate 项目，要求 `config.scenes` 完整
- 它会尽量给 Remotion 加上合适的 browser flags

## 8. `doctor-render-env.mjs`

真源位置：`remotion-video/scripts/doctor-render-env.mjs`

作用：

- 找本地浏览器
- 用 headless 模式测能不能启动

成功信号：

- `Render environment looks healthy for browser startup.`

失败时优先怀疑：

- 浏览器没装
- `REMOTION_BROWSER_EXECUTABLE` 配错
- 当前执行环境拦截了 Chrome 启动

## 9. `snapshots.mts`

真源位置：`remotion-video/scripts/snapshots.mts`

命令：

```bash
npx tsx scripts/snapshots.mts render
npx tsx scripts/snapshots.mts render hero terminal code
npx tsx scripts/snapshots.mts diff
npx tsx scripts/snapshots.mts clean
```

读 / 组装：

- 内置 20-family still fixture
- 每个 family 会叠加 director override，覆盖 `cameraMotion / revealDirection / archetype / dataEvent / memoryObject`

写：

- `remotion-video/__snapshots__/families/*`
- `remotion-video/__snapshots__/manifest.json`
- `remotion-video/__snapshots__/families/*/meta.json`

注意：

- 当前是 20-family still 回归，不是完整视频回归
- 支持定向抽帧，适合 family 改样式后快速比对
- 它已经不是早期组件快照，但仍不能替代人工审片、口播同步和整片验收

## 10. `clean-runtime.mjs`

作用：

- 清理 runtime 相关缓存与临时文件

适用：

- render props 残留
- jobs/logs 太乱
- 本地调试多轮后环境脏了

建议：

- 先看要不要保留 `runtime/jobs` 和 `runtime/logs`

## 11. `voice/qwen-tts-voice.mjs`

真源位置：`remotion-video/scripts/voice/qwen-tts-voice.mjs`

命令：

- `create`
- `ensure`
- `list`
- `delete`
- `synthesize`

典型用法：

```bash
node scripts/voice/qwen-tts-voice.mjs list
node scripts/voice/qwen-tts-voice.mjs synthesize --voice my-voice --text "这是一条测试" --out out/test.wav
```

成功信号：

- 输出 JSON
- `synthesize` 会生成 wav

## 脚本链路建议

### 真正做项目

`run-search-to-ultimate.mjs`

### 只查渲染

`render-ultimate-scene.mjs` -> `verify-render-output.mjs`

### 只查画面风格

`preview-quick.mjs` -> `snapshots.mts`

### 只查语音

`voice/qwen-tts-voice.mjs`

### 只查环境

`doctor-render-env.mjs`
