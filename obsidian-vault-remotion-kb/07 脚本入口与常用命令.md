# 脚本入口与常用命令

## 主入口

### 一站式主入口

```bash
cd /Users/macos/OpenClaw/remotion-generated-video-project/remotion-video
node scripts/run-search-to-ultimate.mjs "你的主题"
```

这个脚本负责：

- workflow 生成
- 分镜与视觉
- 图片生成
- 语音生成
- project 落盘
- render 调度
- phase 汇总

## 常用命令

### 只跑 workflow，不渲染

```bash
node scripts/run-search-to-ultimate.mjs "你的主题" --no-render
```

### 只跳过图片

```bash
node scripts/run-search-to-ultimate.mjs "你的主题" --no-images
```

### 只跳过语音

```bash
node scripts/run-search-to-ultimate.mjs "你的主题" --no-voice
```

### 打开 Storyboard QA

```bash
node scripts/run-search-to-ultimate.mjs "你的主题" --with-storyboard-qa
```

### 恢复已有项目继续跑

```bash
node scripts/run-search-to-ultimate.mjs --project-id gpt55-final-cut --resume
```

## 快速预览

### 单帧 still

```bash
node scripts/preview-quick.mjs --config step-04.json --mode still
```

### 拼联系表

```bash
node scripts/preview-quick.mjs --config step-04.json --mode sheet
```

### 540p 快渲染

```bash
node scripts/preview-quick.mjs --config step-04.json --mode 540p --out previews/test.mp4
```

## 直接渲染 Ultimate

```bash
node scripts/render-ultimate-scene.mjs
```

## QA / 环境

### 视觉回归

```bash
npx tsx scripts/snapshots.mts render
npx tsx scripts/snapshots.mts diff
npx tsx scripts/snapshots.mts clean
```

### 验证输出

```bash
node scripts/verify-render-output.mjs
```

### 环境诊断

```bash
node scripts/doctor-render-env.mjs
```

### 清理 runtime

```bash
node scripts/clean-runtime.mjs
```

## 配音相关

### 千问 TTS 语音

```bash
node scripts/voice/qwen-tts-voice.mjs
```
