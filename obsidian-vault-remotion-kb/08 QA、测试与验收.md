# QA、测试与验收

## 文档真源

- `remotion-video/docs/qa-checklist.md`

## QA 层分三类

### 1. 工程 QA

- `npm run typecheck`
- `node --test server/tests/*.test.js`

### 2. Storyboard QA

- 通过 `--with-storyboard-qa`
- 生成静态分镜图
- 不阻塞主链路

### 3. Render / Visual QA

- `preview-quick.mjs`
- `snapshots.mts`
- `verify-render-output.mjs`

## 验收顺序建议

1. `npm run typecheck`
2. `node --test server/tests/*.test.js`
3. `preview-quick.mjs`
4. `snapshots.mts diff`
5. `verify-render-output.mjs`
6. 最后人工看成片

## Storyboard QA 输出路径

```text
projects/<projectId>/qa/storyboard/
├── storyboard-manifest.json
└── images/
```

## 最终产物验收关注点

- 场景切换是否连贯
- 字幕与语音是否同步
- 图表、对比、数据是否和 payload 一致
- 9:16/16:9 是否符合当前模板目标
- 音量淡入淡出是否自然

## 导演层提醒

现在项目除了传统 QA，还有“导演层 QA”的概念，但这部分更多还在概念和代码准备阶段，还没有完全接入主 CLI 强校验。
