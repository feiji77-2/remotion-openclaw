DirectorScore 预览工具 — 布局方案

三种信息组织方式，核心数据全部展示

A

时间线主导 + 侧边详情

左侧主区域为全宽时间线轨道（acts → shots → cues 分层），点击任一元素右侧面板显示完整属性。

优势

  • 时间维度一目了然
  • cue 重叠/间隙肉眼可辨
  • 适合浏览整体节奏

代价

  • 需要交互才能看细节
  • 所有 cue 同时显示可能拥挤
交互式 轨道视图
B

仪表盘网格

四象限布局：左上时间线 + 右上摄像机路径/能量图 + 左下 cue 数据表格 + 右下属性面板。一屏尽览。

优势

  • 所有信息同时可见
  • 无需点击切换
  • 适合调试排查

代价

  • 每块面板空间有限
  • 小屏/窄窗口显示困难
高密度 调试向
C

垂直滚动叙事

从上到下分段：总览条 → 能量曲线 → 每幕独立时间线（可折叠） → 摄像机路径画廊 → 底部 cue 明细表。

优势

  • 每块都有充足空间
  • 按幕分组自然
  • 导出/截图友好

代价

  • 跨幕对比困难
  • 长视频需要滚动很多
可滚动 按幕分组
